# Projeto_Avaliativo_2
# O projeto avaliativo se chama Estadias e ele serve para realizar reservas em hotéis de uma forma rápida e funcional.
# O projeto utiliza Supabase, Virtual Studio Code e Redis.
# O Supabase é utilizado no projeto para servir como banco de dados dos hoteis cadastrados, perfis de usuários e as reservas feitas pelos hóspedes.
# O Redis é utilizado para auxiliar na busca feita no projeto, criar dados temporários para pagamentos e no geral um motor para aumentar a eficiência do projeto.
